# 📌 Internship Tasks

## ✅ Task 1 – Data Redundancy Removal System

Design and develop a system that identifies duplicate data before it is stored in a database. The project focuses on maintaining data integrity by validating incoming records and ensuring that only unique and verified data is added.

**Key Highlights**

* Duplicate data detection
* Data validation
* Redundancy prevention
* Improved database consistency

---

## ✅ Task 2 – Detecting Data Leaks Using SQL Injection

Develop a secure cloud-based application that protects sensitive user information against SQL Injection attacks while implementing strong encryption and secure access control mechanisms.

**Key Highlights**

* SQL Injection prevention
* AES-256 encryption
* Secure authentication
* Multi-layer security

---

## ✅ Task 3 – Cloud-Based Bus Pass System

Build a scalable online bus pass and ticket booking system capable of handling high traffic while ensuring secure ticket management and reliable cloud deployment.

**Key Highlights**

* Online ticket booking
* Digital bus passes
* Scalable cloud architecture
* Reliable booking experience

---

## ✅ Task 4 – AI Chatbot

Develop an AI-powered chatbot capable of providing instant responses to user queries using retrieval-based or generative AI techniques.

**Key Highlights**

* Intelligent conversations
* Website integration
* Predefined knowledge base
* Improved customer interaction
