\# CodeAlpha Full Stack Development – Task 3



\## Project Management Tool



A full-stack collaborative project management application developed as part of the \*\*CodeAlpha Full Stack Development Internship\*\*.



The application allows users to create and manage projects, assign tasks to project members, communicate through task comments, receive notifications, and receive real-time task updates.



\---



\## 🚀 Features



\- User registration and authentication

\- Project creation and management

\- Project member management

\- Task creation and assignment

\- Task status management

\- Task priority management

\- Due dates

\- Searchable task assignment

\- Task comments and communication

\- Notifications

\- Real-time task updates using WebSockets

\- Role-based permissions

\- Project owner and member access control

\- RESTful API backend
